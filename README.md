# 💌 Kartu Undangan Online Digital

Project Web Undangan Pernikahan / Acara Digital interaktif berbasis Web modern yang cepat, responsif, dan terintegrasi dengan database realtime.

## 🚀 Teknologi yang Digunakan
* **Frontend:** [React.js](https://react.dev/) dengan [TypeScript](https://www.typescriptlang.org/)
* **Build Tool:** [Vite](https://vitejs.dev/) (Cepat dan Ringan)
* **Animasi:** [Framer Motion](https://www.framer.com/motion/) (Untuk efek Floating Dust, transisi halaman, dll.)
* **Database & Backend:** [Firebase Firestore](https://firebase.google.com/) (Untuk menyimpan data RSVP & ucapan tamu secara realtime)
* **Icons:** [Lucide React](https://lucide.dev/)

## 📁 Struktur Folder Utama
* `src/pages/Invitation.tsx` - Halaman utama undangan digital untuk tamu.
* `src/pages/Admin.tsx` - Dashboard admin untuk mengelola daftar hadir (RSVP) dan ucapan.
* `Public/` - Tempat aset publik seperti background musik (`Musik.mp3`) dan logo sponsor.
